# Contribuer à Noxcipher

Les contributions sont les bienvenues. Ouvrez une issue ou une pull request depuis le profil GitHub du projet :
https://github.com/tedyclivel

Avant de proposer une modification, vérifiez que le projet se compile :

```bash
npm run lint
npm run build
```

En contribuant, vous confirmez disposer des droits nécessaires sur votre contribution et acceptez qu'elle soit distribuée sous la licence du projet.

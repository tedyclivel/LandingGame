# Noxcipher

Landing page gaming rendue côté serveur avec Next.js, React, TypeScript, Tailwind CSS, GSAP et Three.js.

## Démarrer le projet

```bash
npm install --legacy-peer-deps
npm run dev
```

Ouvrez ensuite l'adresse affichée dans le terminal, généralement `http://localhost:5173`.

## Scripts

```bash
npm run dev      # serveur de développement
npm run build    # version de production
npm run start    # exécute la version de production
npm run lint     # vérification du code
```

## SEO

Les métadonnées, `robots.txt` et `sitemap.xml` sont générés par Next.js. Avant le déploiement, définissez `NEXT_PUBLIC_SITE_URL` avec l'URL publique du site afin que le sitemap référence votre domaine.
